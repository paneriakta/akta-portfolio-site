How I lead

Three habits that run through the work

01

Decisions shown with their trade-offs

When leadership was split on patching or rebuilding, I did not argue it on looks. I prototyped both options and put them side by side, with what each one would cost.

02

Systems as well as screens

The Nucleus design system, the shared system behind the Task Center, and the thresholds that decide when an AI agent speaks up. Much of the work has no screen of its own.

03

Designers who ship code

I set up Claude Code with the Figma MCP integration so a designer can go from a Figma component to a small production change without switching context.
